The code in the Assistant Link repositories is licensed under the [MIT License](LICENSE). The license covers the code;
it does not cover the project's name or its icon.

- The name "Assistant Link" and the Assistant Link app icon belong to Engineering Freedom Ltd and are not covered by
  the MIT License.
- Forks are welcome. A fork that you distribute, whether as an app, a hosted service, or a binary, must use a different
  name and a different icon, so nobody mistakes it for the official project. Saying that your fork is "based on
  Assistant Link" is fine.
- Official builds come only from the project's own accounts: the `assistant-link` GitHub organization and the
  project's app store listings. Builds published anywhere else are not official.

Using the name to refer to the project, for example in an article, a talk, or an integration's documentation, is fine.

If you are unsure whether a use is allowed, open an issue in
[assistant-link](https://github.com/assistant-link/assistant-link/issues) and ask.
